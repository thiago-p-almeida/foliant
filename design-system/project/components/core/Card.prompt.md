Superfície de conteúdo em neutro quente — nunca cinza frio, nunca branco puro como fundo de tela.

```jsx
<Card surface="card" padding="var(--space-4)">
  <h2 className="fo-heading">O que vai acontecer</h2>
</Card>
```

- `card` (bege) para conteúdo padrão; `sunken` para card dentro de card e campos recolhidos; `brandTint` para reforço de privacidade/seleção.
- Sombra é curta e quente; não empilhe mais de dois níveis de superfície.
