Área de arrastar-e-soltar: fundo `--beige-200` com borda tracejada em repouso, `--blue-100` com borda sólida `--blue-700` quando o arquivo está sobre a janela.

```jsx
<DropZone title="Arraste seu PDF aqui" hint="ou"
  action={<Button variant="secondary">Selecionar arquivo…</Button>}
  note="Aceita PDF de qualquer tamanho — inclusive apostilas de centenas de MB." />
```

Espaçamento generoso (24–32px): é elemento essencial. Raio 12px.
