Campo de texto com rótulo acima e ajuda abaixo — use para título, autor e caminhos de arquivo.

```jsx
<TextField label="Título" placeholder="apostila-direito-adm"
  help="É o nome que vai aparecer na estante do seu aparelho." />
```

- Raio 4px, altura mínima 44px, foco com anel azul (`--blue-600`).
- A ajuda explica o efeito para o usuário, nunca o mecanismo ("é o nome que aparece na estante", não "metadado dc:title").
